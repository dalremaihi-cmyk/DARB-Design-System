# DARB Buttons and Forms

## Responsible Member
Haya

## Overview
Research and design reusable buttons and form components
for the DARB application.

## Tasks

### Buttons
- Identify the button types needed in DARB.
- Design primary and secondary buttons.
- Design different button states.
- Ensure consistency across the application.

| Button Type | DARB Feature / Objective | Example Label | Role |
|---|---|---|---|
| Primary | Apply to opportunity, Submit application, Post opportunity, Publish opportunity | "Apply Now", "Submit", "Post Opportunity", "Publish" | Student / Staff |
| Secondary | Save draft, Cancel, View details, Edit profile | "Save Draft", "Cancel", "View Details", "Edit Profile" | Student / Staff |
| Tertiary / Text | Edit profile, Show more, Read eligibility, Manage skills | "Edit", "Show more", "Read eligibility", "Manage skills" | Student |
| Ghost | Header/nav actions on colored hero, Close banner | "Log out", "Dismiss" | All |
| Destructive | Withdraw application , Delete opportunity , Remove CV , Reject submission | "Withdraw Application", "Delete", "Remove CV", "Reject" | Student / Staff |
| Icon Button | Notifications , Filters , Close dialogs, Message | 🔔 ⚙️ ✕ 💬 | All |
| Split / Dropdown | Messaging options, Status actions for staff | "Message ▾", "Change Status ▾" | Staff |
| Link Button | Navigate to eligibility criteria, Terms, Opportunity details | "Read eligibility criteria", "View terms" | All |
| Toggle / Segmented | Filter opportunity types , Switch feed views (All / Eligible / Applied), Notification options | "All \| Eligible \| Applied", "All \| Unread \| Deadlines" | Student |
| FAB | Mobile: staff post opportunity ; Student quick-apply  | "＋" | Staff / Student |
| File / Upload | Upload CV & certificates  | "Upload CV", "Add Certificate" | Student |
