# DARB Instructor Components: Documentation & Specifications

## 1. Design Tokens & Styling
* **Color Palette:** Strictly uses approved DARB brand tokens (`01-Branding`).
* **Typography:** IBM Plex Sans for English (LTR) and Noto Sans Arabic for Arabic (RTL).
* **Touch Targets:** Minimum interactive target size of 44 × 44px for buttons, tags, and table actions.

## 2. Component Variants & States
* **Form Inputs:** Empty, focused, filled, error validation, and multi-select states.
* **Status Pills:** Paired background color, outline icon, and text label (never relying on color alone).
