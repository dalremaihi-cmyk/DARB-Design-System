# DARB Branding & Color Guidelines

## 1. Brand Overview

DARB is a university student opportunities platform that connects students with internships, competitions, volunteering opportunities, and university events.

### Brand Personality
- Professional
- Modern
- Trustworthy
- Welcoming
- Student-friendly

|---|---|---|
| Primary Blue | #173B57 | Main brand color |

| Light Teal | #D9F0ED | Soft backgrounds |

## 3. Status Colors

| Status | HEX Code | Purpose |
|---|---|---|
| Success | #247A4B | Successful actions |
| Warning | #9A6500 | Warnings and reminders |
| Error | #B42318 | Errors and unsuccessful actions |

## 4. Color Usage Guidelines

- Use Primary Blue for the main brand identity and important elements.
- Use Secondary Teal for buttons, highlights, and interactive elements.
- Use Light Teal for soft backgrounds and highlighted sections.
- Use White for cards and content surfaces.
- Use Background for the main application screens.
- Use Main Text for headings and important information.
- Use Status Colors to communicate system feedback.

## 5. Design Principles

- Maintain consistent color usage across all screens.
- Ensure sufficient contrast between text and backgrounds.
- Avoid using too many colors on one screen.
- Use status colors consistently.
- Do not communicate status using color alone.
